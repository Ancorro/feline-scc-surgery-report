# Surgery for oral squamous cell carcinoma in cats

A short, sourced research report on maxillectomy and mandibulectomy for feline oral squamous cell carcinoma: outcomes, complications, which cats are candidates, and what untreated cats face.

- Public page: https://ancorro.github.io/feline-scc-surgery-report/
- Claude artifact copy: https://claude.ai/artifact/2KNyrF1RYvk6SsZFbQ8jQw

The page is a single `index.html` built from the `research-report` skill template. `sources/` holds a copy of the University of Illinois trial flyer, whose original web address no longer resolves.
